## 큰 그림 한 줄

> **"로컬 state로 앱 만들기"에서 → "서버 데이터를 받아 타입 붙여 화면 그리기"로 건너간다.**
> 완성이 목표가 아니라 **비동기·API·TS를 몸에 붙이는 것**이 목표. 작은 실습으로 확인만.
> 로이떼 이커머스 실전은 다리를 건넌 *다음*, 복귀해서.

```
[지금 위치]                    [이커머스를 혼자 만드는 위치]
로컬 state로                     서버에서 진짜 데이터 받아서
React 앱 만들기      ─────▶      화면 그리고, 타입 붙이고,
(카운터·투두)         이 다리!     Next로 라우팅하는 앱
```

### ❌ 이 한 달의 표적 (아직 0 — 하나의 다리)

3. **TypeScript** (프로젝트가 이미 TS)

## 🚫 이 한 달에 안 하는 것
- ❌ 이정환 리액트 처음부터 다시 듣기 → 복습은 "다시 듣기"가 아니라 "써보면서"
- ❌ HTML/CSS 공부 → 강점, 시간 낭비
- ❌ 강의 여러 개 동시 → 최악의 함정. 한 주 = 강의 하나
- ❌ 큰 프로젝트 완성 압박 → 안전 모드, 작은 실습만
- ⚠️ 건강 회복 우선. 무리한 계획은 2주차에 무너짐

## 🗓️ 4주 설계

### 1주차 — 비동기 정복 🔵 (제일 중요)
> 학습 로드맵에서 유일하게 못 건넌 M3. 이거 없이 API 못 함.

- 자료: 🎬 떠먹는 자바스크립트 비동기(메인) + 📘 Deep Dive 42·45·46장(사전) + 🧑‍🏫 세션
- 목표 개념: 콜스택 → 이벤트 루프 → Promise(대기/성공/실패) → `.then` → `async/await`
- 아웃풋: `setTimeout`·`Promise`·`async` 콘솔 손코딩, "동기 vs 비동기" 자기 말로

- [ ] 동기 vs 비동기가 뭔지 + 왜 필요한지 (콜스택·클로저 연결)
- [ ] 콜백과 콜백 지옥
- [ ] Promise (대기/성공/실패 3상태)
- [ ] `.then` / `.catch`
- [ ] `async` / `await`
- [ ] 이벤트 루프 (마이크로태스크 vs 태스크)
- [ ] 손코딩: setTimeout·Promise·async 직접 짜보기

### 2주차 — API 연결 (진짜 데이터!)

- `useEffect` 안에서 데이터 페칭 / 로딩·에러 상태 처리 / `axios`로 갈아타기
- 아웃풋: "상품 목록"을 API에서 받아 카드로 그리기 (이커머스의 심장)

- [ ] fetch 기본 + `.json()`

- [ ] 로딩 / 에러 상태 처리
- [ ] axios로 전환
- [ ] 아웃풋: 공개 API에서 목록 받아 카드 렌더

### 3주차 — TypeScript
- 이정환 TS 강의 (한 주 강의 하나)
- `string`/`number`/`interface`/`type`/제네릭/union 기초 → 2주차 화면에 타입 얹기
- 아웃풋: API 응답 타입, props 타입, some-theme-front 코드 읽기

- [ ] 기본 타입 (string/number/boolean/array)
- [ ] interface vs type
- [ ] 함수 타입 / props 타입
- [ ] 제네릭 기초

- [ ] 아웃풋: 2주차 API 화면에 타입 얹기

### 4주차 — 통합 + 로이떼 준비 (안전 모드)
- 작은 통합 실습: "API에서 상품 목록 → 상세 (TS + 라우팅)" 한 흐름만
